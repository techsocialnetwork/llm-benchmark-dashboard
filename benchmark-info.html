📊 Benchmark Explanations

MMLU (Massive Multitask Language Understanding)

Tests knowledge across 57 subjects (math, history, law, medicine, etc.). Higher is better. 80%+ = excellent, 70-80% = good, <70% = average.

HumanEval

Measures code generation ability (164 programming problems). Higher is better. 80%+ = excellent coder, 70-80% = good, <70% = basic.
